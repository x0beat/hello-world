# English Cards - Приложение для изучения английского языка

## Описание

**English Cards** - это iOS приложение для изучения английского языка с помощью карточек. Приложение содержит набор английских слов с переводами, транскрипцией и примерами использования.

## Особенности

### 🎯 Основные функции
- **Карточки со словами** - более 20 английских слов с переводами
- **Транскрипция** - правильное произношение каждого слова
- **Примеры использования** - предложения на английском и русском языках
- **Интерактивное обучение** - нажмите на карточку, чтобы увидеть перевод

### 🎨 Интерфейс
- **Современный дизайн** - красивый градиентный интерфейс
- **Анимации** - плавные переходы между карточками
- **Прогресс бар** - отслеживание прогресса изучения
- **Адаптивный дизайн** - подходит для iPhone и iPad

### 📱 Функциональность
- **Навигация** - кнопки "Назад" и "Вперед"
- **Перемешивание** - случайный порядок карточек
- **Показать/Скрыть** - переключение между вопросом и ответом
- **Циклическое воспроизведение** - автоматический возврат к началу

## Как использовать

### 🚀 Установка
1. Откройте проект в Xcode 15.0 или новее
2. Выберите устройство или симулятор iOS 17.0+
3. Нажмите CMD+R для запуска приложения

### 🎮 Управление
- **Нажмите на карточку** - показать/скрыть перевод
- **Стрелки влево/вправо** - навигация между карточками
- **Кнопка "Показать/Скрыть"** - переключение перевода
- **Кнопка перемешивания** - случайный порядок карточек (в навигационной панели)

### 📚 Содержание
Приложение включает слова на темы:
- Базовые слова (Hello, World, Time)
- Семья и дом (Family, House, Friend)
- Обучение (Study, Learn, Book, School)
- Эмоции (Happy, Love, Beautiful)
- Повседневная жизнь (Work, Food, Water)
- Хобби (Travel, Music, Dream)

## Архитектура

### Модель данных
```swift
struct FlashCard: Identifiable, Codable {
    let id = UUID()
    let english: String        // Английское слово
    let russian: String        // Русский перевод
    let transcription: String  // Транскрипция
    let example: String        // Пример на английском
    let exampleTranslation: String // Перевод примера
}
```

### Состояние приложения
```swift
class WordsData: ObservableObject {
    @Published var cards: [FlashCard]    // Массив карточек
    @Published var currentIndex: Int     // Текущая карточка
    @Published var showingAnswer: Bool   // Показывать ответ
}
```

# Быстрый запуск English Cards

## Что это?
iOS приложение для изучения английского языка с интерактивными карточками.

## Как запустить?

### 1. Откройте проект в Xcode
```bash
# Перейдите в папку проекта
cd EnglishCards

# Откройте проект в Xcode
open EnglishCards.xcodeproj
```

### 2. Выберите симулятор
- В Xcode выберите iPhone симулятор (любой iPhone)
- Убедитесь что выбран iOS 17.0 или новее

### 3. Запустите приложение
- Нажмите ▶️ (Play) или CMD+R
- Приложение запустится в симуляторе

## Как пользоваться?

### 🎯 Основные действия:
1. **Нажмите на карточку** - покажет перевод
2. **Стрелки ← →** - переключение между карточками  
3. **Кнопка "Показать/Скрыть"** - альтернативный способ показать перевод
4. **Кнопка 🔀** (в верхнем правом углу) - перемешать карточки

### 📚 Что изучается:
- 20 английских слов с переводом
- Транскрипция произношения
- Примеры использования
- Перевод примеров

### 🎨 Интерфейс:
- Прогресс бар показывает текущую карточку
- Красивые анимации переходов
- Градиентный дизайн

## Системные требования
- macOS с Xcode 15.0+
- iOS 17.0+ (для устройства)
- iPhone/iPad симулятор
